# Música de la introducción

Coloca aquí el archivo instrumental con el nombre `wedding-intro.mp3`.

La web intenta reproducirlo solo después de pulsar **Entrar**, aplica una entrada progresiva de volumen y muestra un control discreto. Si el archivo no existe, el control se oculta y el resto de la experiencia sigue funcionando.

Usa un MP3 optimizado, sin voz y con licencia válida; preferiblemente por debajo de 4–5 MB.
